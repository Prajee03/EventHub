EventHub 📅
==============================

EventHub is a simple and responsive event website created using HTML and CSS.
It allows users to discover upcoming events, view event details, and get
contact information.

FEATURES
--------
- Upcoming events section
- Event images
- Event location and time
- Event action buttons
- Modern and clean UI design
- Responsive design for mobile devices
- Sticky navigation bar
- Hover effects and smooth scrolling
- Contact information section
- External link to Flipkart

TECHNOLOGIES USED
-----------------
- HTML5 - Structure of the website
- CSS3 - Styling, layout, animations, and responsive design

HOW TO RUN
----------
1. Download or clone this project.
2. Make sure the img folder is present in the same project directory.
3. Open index.html in any web browser.
4. The EventHub website will open locally.

WEBSITE SECTIONS
----------------
1. Navigation Bar
   The navigation bar contains links to:
   - Home
   - Events
   - About
   - Contact

2. Hero Section
   The hero section introduces EventHub with the heading:
   "Discover Amazing Events"

   It also includes an "Explore Events" button that takes the user
   to the events section.

3. Upcoming Events
   The website currently displays upcoming events such as:

   - Photo Gallery Event
     Date: 15 October
     Location: Trichy
     Time: 10:00 AM

   - Flipkart Upcoming Sale
     Date: 20 October
     Location: Online
     Time: All Day

4. Call-to-Action Section
   A CTA section encourages users to mark their calendars and get in touch.

5. Contact Section
   The contact section provides phone, email, and address information.

6. Footer
   The footer displays the EventHub copyright information.

RESPONSIVE DESIGN
-----------------
The website includes CSS media queries for smaller screens.

On mobile devices:
- The navigation menu is hidden.
- Event cards change from two columns to one column.
- Heading sizes are reduced.
- The hero section becomes smaller.

DESIGN
